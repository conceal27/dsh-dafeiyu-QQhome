# NapCat 常见问题 & 「我自己的 NapCat」接入指南（归属：xingzhu）

> 这篇回答两个最常被问的问题：
> 1. **社区协议端 NapCat 有什么问题/风险？**
> 2. **我已经有自己的 NapCat，怎么接到主星上的大肥鱼 上？**
> 官方 QQ 机器人的能力边界见 README FAQ Q9。

---

## 一、先说结论

| 你想做的事 | 能不能用官方 QQ 机器人 | 能不能用 NapCat |
|---|---|---|
| 用**你自己的 QQ 号**聊天（不是另建一个 bot 号） | ❌ 不能扫码接管个人号 | ✅ 可以（注入本机 QQ NT） |
| 看好友/群列表、本地聊天记录 | ❌ 无接口 | ✅ 有（OneBot 11 + 本地记录） |
| 主动给好友/群发消息 | ⚠️ 额度/权限受限、个人主体几乎不可用 | ✅ 可以（注意频控与风控） |
| 合规性 | ✅ 官方 | ❌ 非官方、不符合腾讯用户协议 |
| 账号风险 | 无（bot 号独立） | ⚠️ 个人号可能被风控/强制下线/封禁 |
| 上手门槛 | 主体认证 + AppID/AppSecret + 上线审核 | 装 NapCat + 扫码即可 |

**所以本插件选 NapCat**：需求是「用我自己的号陪聊 + 看记录 + 主动推一句」，官方机器人根本做不到。
代价是个人号风险，因此插件把「用小号、知情同意」做成了必须先勾选的前置闸门。

## 二、NapCat 本身有哪些问题/风险（按重要度排序）

### 1. 账号风险（最需要重视）
- NapCat 是社区协议端，通过注入官方 QQ NT 客户端工作，**不是腾讯官方接口，不符合腾讯用户协议**。
- 可能被：强制下线、临时冻结、限制登录、永久封禁（社区里都出现过）。
- **强烈建议用小号**跑插件，主号不要用；插件默认关闭自动回复/推送，先确认再逐项开。
- 不要拿它做群发、营销、爬取他人信息——既违反平台规则，也最容易触发风控。

### 2. 同一个 QQ 号不能同时登录「桌面 QQ」和 NapCat
- 一个号同一时间只有一个登录态。NapCat 接管后，桌面 QQ 会被顶下线（或反过来）。
- 解法：小号跑 NapCat、主号用桌面 QQ；或只用其中一个。
- 面板检测到 QQ 在运行时会提示「关闭 QQ 并继续」，**只结束插件探测到的那份 QQ.exe**，不会乱杀进程。

### 3. 权限与杀毒软件
- Windows 的 `launcher.bat` 注入需要管理员权限（UAC 弹窗是正常的）；`launcher-user.bat` 理论上可免提权，但不是所有环境都行。
- DLL 注入容易被 Windows Defender / 杀软启发式拦截（表现为启动失败、QQ 闪退、hook 不生效）。
- 解法：把托管目录 `%USERPROFILE%\.dsh\qq-fish\napcat\` 加白名单后重试；仍被拦就走「自己的 NapCat」+ 外部模式（你自己装、自己启动，插件只连 OneBot）。

### 4. 版本兼容（社区维护，QQ 一更新就可能失效）
- QQ NT 自动更新后，注入可能失效；NapCat 社区通常几天内跟进，需要更新 NapCat。
- 社区里有「某个 QQ 版本 + 某个 NapCat 版本」才稳的经验组合，升级前先看 NapCat 的 Release 说明。
- 表现：启动器没反应、QQ 起了但 NapCat 没连上、登录后立刻掉线。

### 5. 托管安装的平台限制
- 本插件的**一键安装/启动只做 Windows**（因为要走 QQ NT 注入）。
- macOS / Linux 请自己跑 NapCat（Docker 或本机安装），然后用本文的「外部模式」接进来。

### 6. 下载与网络（国内）
- 安装包只在 GitHub Releases：直连经常慢/中断。`0.1.2` 起插件**默认先走公共加速**（用户镜像 → gh-proxy.com → ghproxy.net → ghfast.top → GitHub 直连），某个源 **20 秒没有进度会自动中止并换下一个源**，日志会写「改用下载镜像：xxx」。
- **DSH「添加插件」里的「中国大陆镜像源」只加速 npm 包，不管 NapCat 安装包下载**；NapCat 下载源由插件自己控制，可在「高级：我自己有 NapCat → GitHub 下载镜像」里自定义。
- 如果提示 **「获取 NapCat 最新版本失败：HTTP 403」**：这是 GitHub API 未登录限额（每小时 60 次，共用出口 IP 很容易触发）。`0.1.1` 起会自动退回 `releases/latest` 页面解析版本，不再让 DSH 崩溃；若仍失败，等约 1 小时/换网络，或手动下载 NapCat 包解压到 `qq-fish\napcat\<版本号>\` 后点「重新检测」。
- 下载太慢：安装进度条右侧有「取消安装」，取消后重试会自动换源；也可以点进度条下方「手动下载 NapCat 包」。
- ⚠️ 第三方镜像不保证文件完整性：插件会校验 zip 头、解压前预检路径穿越；也可手动下载后解压到 `qq-fish\napcat\<版本号>\` 再点「重新检测」。

### 7. WebUI / OneBot 的暴露面
- NapCat WebUI 默认可能监听 `0.0.0.0:6099`，OneBot WS 默认也可能是 `0.0.0.0`。**暴露到公网 = 别人可以操作你的 QQ**。
- 必须：只绑 `127.0.0.1`、设置随机 token、不要端口映射/内网穿透；不用时关掉。
- 插件的托管模式会自动用 `127.0.0.1` + 随机 token；外部模式请自己检查。

### 8. 稳定性与重连
- NapCat 可能崩溃、被强制下线、Worker 重启；QQ 也会把异常登录踢下线。
- 插件有 WS 指数退避重连、心跳超时判定、NapCat 进程 watchdog；**但不要频繁重登**——频繁重登本身是风控触发点。
- 被踢下线时：先去手机 QQ 做安全验证，等几分钟、换个网络再试，别连着重启。

### 9. 功能边界
- 本插件目前只处理**文本**消息；图片/语音/文件在聊天记录里显示为占位符（不会去解析）。
- NapCat 历史消息/快捷登录列表的字段随版本变化，插件做了多别名容错，但极端版本可能缺字段。
- WebUI 开了两步验证（2FA）时插件无法自动登录，需要先在 NapCat 里关掉 2FA。

### 10. 无官方支持
- NapCat 是社区项目，没有腾讯 SLA；出问题查它的文档 / GitHub Issues。插件只能把能诊断的信息（端口、日志尾巴、错误人话）显示在面板里。

## 三、我已经有自己的 NapCat：怎么接进来

> 适用：本机已装好 NapCat、macOS/Linux、或托管安装/启动失败想手动接管。
> 外部模式下，插件**只负责连 OneBot 和面板展示**：不会安装/启动/停止/杀你的 NapCat，也不会改它的配置。

### 3.1 先确认 NapCat 自己是好的
1. 启动 NapCat（Shell/Installer/Framework 按你的安装方式）；
2. 手机 QQ 扫码登录成功；
3. 打开 WebUI（默认 `http://127.0.0.1:6099`）能看到面板；
4. 能在 NapCat 里看到登录账号。

### 3.2 开一个 OneBot 11 正向 WebSocket（必须）
两种做法任选：

**A. 在 NapCat WebUI 里点（推荐）**
网络配置 → 新建 **WebSocket 服务器（正向 WS）**：
- host：`127.0.0.1`（**不要** `0.0.0.0`）
- port：例如 `3001`（被占了换一个，记住它）
- token：设一个随机串（强烈建议；可空，但空 token 等于谁都能连）
- 消息格式：`array`
- 心跳：`30000`

**B. 改配置文件**（`<NapCat 工作目录>/config/onebot11.json`，工作目录默认是 NapCat 程序目录；可用 `NAPCAT_WORKDIR` 覆盖）：
```jsonc
{
  "network": {
    "websocketServers": [
      {
        "name": "dsh-qq-fish",
        "enable": true,
        "host": "127.0.0.1",
        "port": 3001,
        "messagePostFormat": "array",
        "reportSelfMessage": true,
        "token": "换成一串随机字符",
        "debug": false,
        "heartInterval": 30000
      }
    ]
  },
  "musicSignUrl": "",
  "enableLocalFile2Url": false,
  "parseMultMsg": false
}
```
- `reportSelfMessage: true` = 你在手机/别处发的消息也上报（聊天记录更完整）；不需要可改 `false`。
- 改完重启 NapCat，然后确认端口在听：`Test-NetConnection 127.0.0.1 -Port 3001`（PowerShell）。

### 3.3（可选）让插件面板帮你看二维码 / 登录态
不填也能用——你自己在 NapCat 里扫码登录即可。填了之后插件可以：
- 在面板里直接显示二维码、刷新二维码、轮询「已扫码/已登录」；
- 显示「快速登录（用过的账号）」并一键登录；
- 显示登录账号（脱敏）。

需要的信息：NapCat **WebUI 地址 + token**。
- 地址：通常 `http://127.0.0.1:6099`（端口被占会自动 +1，以 NapCat 日志/`config/webui.json` 为准）；
- token：`config/webui.json` 里的 `token`；或启动时环境变量 `NAPCAT_WEBUI_SECRET_KEY` 指定的值；
- 注意：WebUI token 不是 OneBot token，两者不是一个东西。

### 3.4 在插件面板里填（点哪里）
1. 打开「主星上的大肥鱼」面板 → **概览**；
2. 滚到 **QQ 桥（NapCat）** 卡片 → 展开 **「高级：我自己有 NapCat」**；
3. 填：
   - **OneBot WebSocket 地址（必填）**：`ws://127.0.0.1:3001`（按你 3.2 的端口）
   - **OneBot token**：3.2 里设的 token（有就填，输入框不回显）
   - **WebUI 地址（可空）**：`http://127.0.0.1:6099`
   - **WebUI token（可空）**：3.3 的 WebUI token
4. 点 **「保存并使用」**。
   - 插件会切到外部模式并立刻尝试连 WS；面板顶部「QQ 桥」变「在线」即成功。
   - 连不上会显示人话错误：先查端口有没有开、token 是否一致、NapCat 是否还登录着。
5. 如果填了 WebUI：回「概览」二维码卡，会显示当前登录态/快速登录列表；没填就在 NapCat 里自己登录。

### 3.5 接好后的自检清单
- [ ] 面板「QQ 桥」= 在线；账号显示（脱敏）正确；
- [ ] 手机 QQ 给这个号发一条消息 → 面板「聊天」出现记录（带时间戳）；
- [ ] 「人设」里打开自动回复 → 再发一条，能按人设回；
- [ ] 面板「聊天 → 同步联系人」能拉到好友/群；
- [ ] 想主动推送/碎碎念：在「推送与安全」设目标、打开开关；
- [ ] 填了 WebUI 的话：二维码卡能看到登录态，重启 DSH 后插件会自动重连（不会自动启动你的 NapCat，需要你自己保证它在跑）。

### 3.6 想切回「插件托管」怎么办
外部模式目前没有一键切回按钮，手动改配置即可（改完重启 DSH）：
1. 打开 `%USERPROFILE%\.dsh\qq-fish\config.json`；
2. 把 `"onebotMode": "external"` 改成 `"managed"`；
3. 清空 `"wsUrl" / "wsToken" / "webuiUrl" / "webuiToken"`；
4. 重启 DSH，面板会重新按托管模式探测/启动 NapCat。

### 3.7 安全基线（外部模式同样适用）
- WebUI 与 OneBot 都只绑 `127.0.0.1`；不要端口映射、不要内网穿透；
- 两个 token 都设随机串，不要贴聊天/截图/公开仓库；
- 用**小号**；不在用时在 NapCat 里关掉服务；
- 卸载：删 `%USERPROFILE%\.dsh\qq-fish`（聊天记录/token 都在里面），你的 NapCat 安装目录自己决定留不留。

## 四、常见报错对照

| 现象 | 可能原因 | 处理 |
|---|---|---|
| 保存后一直「未连接」 | WS 端口没开/写错、host 不是 127.0.0.1、防火墙拦 | 先 `Test-NetConnection 127.0.0.1 -Port 3001`；核对 NapCat 网络配置 |
| 401 / Unauthorized | OneBot token 不一致 | 两边改成同一个 token，重新保存 |
| 能连上但不收消息 | NapCat 掉登录/WS 只开了 HTTP；`reportSelfMessage` 无关 | 看 NapCat 是否在线；确认开的是 **WebSocket 服务器** |
| 二维码拉不出来 | WebUI 地址/token 错、端口漂移、开了 2FA | 用 `config/webui.json` 的实际端口/token；关 2FA |
| 登录后马上掉线 | 同账号在别处登录/风控 | 退出桌面 QQ、等几分钟再登，别频繁重试 |
| 启动器一闪而过/注入失败 | UAC 没给、杀软拦、QQ 版本不兼容 | 加白名单、更新 NapCat、或改外部模式 |

## 五、一分钟短答（给别人解释用）

- **NapCat 安全吗？** 不是官方东西，有封号风险；用小号、低频、别营销，风险自担。
- **为什么不直接用官方机器人？** 官方 bot 不是你的号，不能扫码接管，也没有好友/历史记录和可用的主动推送。
- **我能不装桌面 QQ 吗？** 可以：用自带 QQ 的 `NapCat.Shell.Windows.Node.zip`（118MB），或自己装 NapCat Framework + LiteLoader。
- **插件会上传我的聊天吗？** 不会。聊天记录/配置/token 只在本机 `$DSH_HOME/qq-fish/`；NapCat 本身也是本地协议端（但它是社区代码，自行评估）。
- **一台机器能挂几个号？** 一个插件实例对应一个 NapCat 登录；多号需要多开实例/多 profile，并注意机器与网络风控。
