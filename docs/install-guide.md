# 主星上的大肥鱼 · 安装指南（Windows 小白版）

本指南比 README 更细：从零开始，一步一步来。全程只需要鼠标 + 手机 QQ。
如果你卡在某一步，先看最后一节「排错速查表」。

> ⚠️ 开始前请确认：这是**个人 QQ 号**的社区协议方案（NapCat / OneBot 11），
> 不是腾讯官方接口，**有被风控/封禁的风险，请用小号**。详见
> [SECURITY.md](../SECURITY.md)。

---

## 0. 准备清单

| 需要 | 说明 |
|---|---|
| Windows 10 / 11 | 托管安装只支持 Windows；Win10 用 `launcher-win10.bat` 的场景插件会自动选 |
| DeepSeek Harness 桌面版 | 0.2.1-rc.3 或更新；能正常打开对话页 |
| 一个 **QQ 小号** | 手机 QQ 已登录该号，能扫码 |
| 管理员权限 | 启动 NapCat 会弹 UAC，需要你点「是」 |
| 网络 | 能装 npm 包、能访问 GitHub Releases（下载 NapCat）；直连失败时插件会自动换镜像 |
| 磁盘 | 150 MB 起（带 QQ 的包约 300 MB） |

**开始前先做两件事：**

1. 电脑上的**桌面版 QQ 先退出**（同一个号不能两处同时登录）；忘了也没关系，装完面板会
   提示，届时可以退出后点「启动 QQ 桥」，或点「关闭 QQ 并继续」；
2. 想好一个**人设**：她叫什么名字、说话什么风格（之后也能改）。

## 1. 安装插件

### 1.1 在 DSH 里安装

1. 打开 DSH 桌面版；
2. 左侧栏找到「**插件**」；
3. 点右上角「**添加插件**」；
4. 在输入框填入下面之一，点「安装」：
   - `dsh-dafeiyu-home`（从 npm 安装，发布后可用）
   - `~/dsh-dafeiyu-home`（本地目录，开发用，换成你本机实际路径）
   - `dsh-dafeiyu-home-0.1.0.tgz` 的绝对路径（离线包）
5. 看到「安装完成」后点「**立即启用**」；
6. 回到页面按 **Ctrl + Shift + R** 强刷。

**你会看到**：左侧栏多了一个「主星上的大肥鱼」的图标（气泡鱼样式），点开就是面板。

**如果没出现：**

- 看「设置 → 内置插件」里有没有 `dsh-dafeiyu-home`（只读清单）；
- 有的话回「插件」页看它有没有异常标签（`not-bundle` 说明装错了包）；
- 提示 `restart-required` 就关掉 DSH 重新打开，再强刷页面。

### 1.2（可选）命令行安装

```powershell
dsh plugin --profile web add dsh-dafeiyu-home
dsh plugin --profile web add ~/dsh-dafeiyu-home
```

桌面版的 profile 一般叫 `desktop`，但官方说桌面版的包管理由 Desktop 壳负责，
普通用户优先用 1.1 的界面安装。装完同样要重启 DSH / 强刷页面。

## 2. 打开面板，先做风险确认

1. 左侧栏点「**主星上的大肥鱼**」；
2. 上方会显示「未连接」，下面有「初次使用 · 四步开始」的向导卡片；
3. 点「**推送与安全**」标签；
4. 勾选「**我用的是小号，已知可能被风控 / 封禁，并自行承担风险**」；
5. 点「**我已了解，确认**」；

> 为什么必须勾：没勾之前，安装/启动 QQ 桥、登录、主动推送都会被拒绝，并提示你先勾选。
> 这是插件有意做的「知情同意」闸门。

---

## 3. 安装并启动 QQ 桥（NapCat）

回到「**概览**」，点「**连接 QQ**」（也可能写「一键安装 QQ 桥」）。

### 3.1 自动安装会发生什么

面板会显示进度条（可展开看日志），一般顺序是：

1. **探测**：找本机 QQ 和已装的 NapCat；
2. **下载**（只下载一次，约 34 MB 或 118 MB）：
   - 本机已装官方 QQ → `NapCat.Shell.zip`（约 34 MB，用你已有的 QQ）；
   - 本机没有 QQ → 带 QQ 的整合包（约 118 MB，避免版本问题）；
   - **自动换源**：安装时按顺序尝试：你填的镜像（如填了）→ GitHub 直连 →
     `gh-proxy.com` → `ghproxy.net`；上一个失败就换下一个，日志里会显示
     「改用下载镜像：xxx」；
3. **解压**：到 `%USERPROFILE%\.dsh\qq-fish\napcat\<版本号>\`（升级会保留配置）；
4. **写配置**：WebUI 和 OneBot 都只监听 `127.0.0.1`，端口自动挑空闲的，token 随机生成；
5. **启动**：可能弹 **UAC**；
6. **等二维码**：最多约 90 秒。

### 3.2 QQ 正在运行时

NapCat 要接管 QQ，所以本机不能有同一个 QQ 在跑。安装完成后如果看到「需要先退出 QQ」：

- 方式 A（推荐）：手动退出电脑上的桌面 QQ，回面板点「**启动 QQ 桥**」；
- 方式 B：点面板上的「**关闭 QQ 并继续**」——它只结束插件探测到的**那一份** `QQ.exe`，
  然后自动尝试启动 NapCat；探测不到安装路径或进程路径时会**拒绝动手**，让你手动退出。

> 面板不会偷偷杀你的 QQ；「关闭 QQ 并继续」需要你点按钮才会执行。

### 3.3 UAC 弹窗

- 弹窗标题类似「用户账户控制」，程序是 `launcher.bat` / `NapCatWinBootMain.exe`；
- 这是正常的：NapCat 要向 QQ 进程注入 hook，需要管理员权限；
- 点「**是**」；点「否」会启动失败，面板会提示权限不足。

### 3.4 失败怎么办

| 看到什么 | 怎么办 |
|---|---|
| 一直停在「下载中」 | 等着它自动换源（日志会显示「改用下载镜像：xxx」）；可提前在「QQ 桥」卡片填「GitHub 下载镜像」，或手动下载（见 5.3） |
| 三个源都下载失败 | 手动下载官方包解压到 `qq-fish\napcat\<版本号>\` 后点「重新探测」，或走进阶路径 |
| 提示需要先退出 QQ | 退出桌面 QQ 后点「启动 QQ 桥」，或点「关闭 QQ 并继续」（见 3.2） |
| 下载完成但解压失败 | 常见于杀软拦截：把 `qq-fish\napcat\` 加白名单后重试；具体原因写在 `qq-fish\napcat-install-error.json` |
| 卡在「启动中」 | 看日志里的 `lastError`；确认 QQ 已退出；重试一次；仍不行走进阶路径 |
| 提示需要管理员权限 | UAC 被拒绝了：重新点「连接 QQ」，在弹窗点「是」 |
| 端口被占 | 插件会自动重选；日志里会显示实际端口 |

## 4. 手机扫码登录

1. 面板出现二维码（大图居中；没有二维码就点「**获取二维码**」或「**刷新二维码**」）；
2. 手机 QQ（已登录**小号**）→ 右上角「**+**」→「**扫一扫**」；
3. 扫描 → 手机上点「**确认登录**」；
4. 面板状态会依次变化：

```
等待扫码 → 已扫码，请在手机上确认 → 初始化中 → 已登录
```

**成功标志**：概览显示账号（脱敏，如 `12****78`）和「在线」，消息收发开始正常。

**常见问题：**

| 情况 | 处理 |
|---|---|
| 二维码过期（约 2 分钟） | 点「刷新二维码」重扫 |
| 手机点取消 | 回到等待扫码，重扫 |
| 已登录的号与桌面 QQ 冲突 | 退出桌面 QQ 后重试 |
| 之前登录过、列表里有「一键登录」候选 | 点对应账号可一键复用，省一次扫码 |
| 扫码后一直「初始化中」 | 等 20～30 秒；仍不动就重启 QQ 桥（概览 → 停止/启动） |

## 5. 进阶路径：我自己有 NapCat

适合：自己装过 NapCat、想用固定端口、macOS / Linux、或自动安装失败。

> 更完整的 NapCat 风险清单、OneBot 11 配置 JSON 示例、外部模式自检清单与报错对照，
> 见 [napcat-faq.md](napcat-faq.md)。

### 5.1 在你的 NapCat 里开 OneBot 11

1. 打开 NapCat WebUI（默认 `http://127.0.0.1:6099`）；
2. 进「网络配置」→「添加」→「WebSocket 服务器」；
3. 填：
   - `host`：`127.0.0.1`（**不要** `0.0.0.0`）
   - `port`：`3001`（空闲即可）
   - `token`：随机串，记下来（强烈建议设置）
   - 消息上报格式：`array`；心跳间隔：`30000`
4. 启用并确认 NapCat 已登录（手机扫码）。

### 5.2 在插件面板里切外部模式

1. 「概览」→ 展开「**高级：我自己有 NapCat**」；
2. 填：
   - `wsUrl`：`ws://127.0.0.1:3001`（必填）
   - `wsToken`：NapCat 里那个 token
   - `webuiUrl` / `webuiToken`（可选）：填了插件才能替你拉二维码、看登录态；
3. 保存 → 面板切换到外部模式。

> 外部模式下插件**不会**启动/停止/删除你的 NapCat 进程，这是有意的，避免误杀你正在用的实例。
> 「紧急停止」也只断插件侧的连接与定时器。

### 5.3 手动下载 NapCat（网络不通时）

1. 浏览器打开 `https://github.com/NapNeko/NapCatQQ/releases`；
2. 下载 `NapCat.Shell.zip`（已有 QQ）或 `NapCat.Shell.Windows.Node.zip`（自带 QQ）；
3. 解压到 `%USERPROFILE%\.dsh\qq-fish\napcat\<版本号>\`，确认里面能看到 `launcher.bat`；
4. 回面板点「重新探测」，再点「连接 QQ」。

> 插件会自动换源下载（按 你填的镜像 → 直连 → 公共镜像 的顺序），日志显示「改用下载镜像：xxx」。第三方镜像
> 不保证文件完整性；插件会校验 zip 文件头，并在系统自带 tar 可用时预检条目路径（拒绝路径穿越），
> 但更稳的是直连官方或手动下载。你也可以在「QQ 桥」卡片里填自己的「GitHub 下载镜像」。

## 6. 第一次聊天（验证）

1. 「人设」→ 改名字（如「小肥鱼」）和说话方式 → **保存人设**；
2. 「概览」→ 打开「自动回复」（默认是关的）；
3. 用**另一个 QQ**（或手机小号）给这个号发一句私聊；
4. 看面板「聊天」：应该有入站记录和回复，时间戳对得上。

群里默认只回「被 @」的消息；想全回再开「群里也回」，但别长期开（容易刷屏 + 风控）。

## 7. 断电 / 重启电脑 / 关闭 DSH 之后

- **配置与数据不丢**：都在 `qq-fish\` 里；
- 重新打开 DSH：插件会挂载面板，状态先显示「未连接」；
- 托管模式：默认会自动拉起 NapCat 并重连（前提是风险确认已勾、上次登录还在）；
  如果没自动连上，去「概览」点「连接 QQ / 启动」；
- 如果自动拉起时提示 QQ 在运行：按第 3.2 节退出 QQ 后再点「启动 QQ 桥」，或点「关闭 QQ 并继续」；
- 登录态掉了（比如手机上退出了）：面板会提示重新扫码；
- **不要**在掉线时反复重启登录，等几分钟或换网络再试。

## 8. Windows 10 / 11 注意事项

- **Win10**：NapCat 的启动器走 `launcher-win10.bat`（插件会判断）；其余流程一样；
- **UAC**：每次启动 NapCat 都需要授权，除非你改了系统的 UAC 设置（不建议）；
- **杀软 / Defender**：NapCat 的注入行为可能被拦，把 `qq-fish\napcat\` 加白；
- **路径**：托管目录固定为 `qq-fish\napcat\<版本号>\`，不要把 NapCat 挪到中文/带空格路径下手动启动；升级时保留配置；
- **睡眠/休眠**：电脑睡眠会导致断线，唤醒后等插件自动重连；
- **多用户**：`qq-fish\` 在用户目录下，别人登同一个 Windows 账户能看到聊天记录和 token，
  请用单用户机器或开启磁盘加密。

---

## 9. macOS / Linux

- 本插件的「一键安装/托管启动 NapCat」**只做了 Windows**，其它系统会提示使用进阶路径；
- 你需要自己把 NapCat 跑起来（具体支持情况以 NapCat 官方文档为准：Windows / Linux / Docker
  等形态），并在它的配置里开好 OneBot 11 正向 WebSocket（`127.0.0.1` + token）；
- 然后在 DSH 插件面板走第 5 节的「我自己有 NapCat」填 `wsUrl`（+ 可选 `webuiUrl`）；
- 进阶路径与系统无关，面板、聊天记录、推送这些功能照常可用。

---

## 10. 卸载与清理

1. 「推送与安全」→ **紧急停止**；
2. 退出 DSH；
3. 「插件」页卸载「主星上的大肥鱼」（或 `dsh plugin --profile <profile> remove dsh-dafeiyu-home`）；
4. 删除 `%USERPROFILE%\.dsh\qq-fish`（聊天记录 + token + 托管 NapCat）；
5. 外部模式的 NapCat 需要你自己去关服务 / 删除。

## 11. 排错速查表

| 现象 | 最可能的原因 | 处理 |
|---|---|---|
| 左侧栏没有图标 | 插件没启用 / 页面没刷新 | 插件页确认开关 → Ctrl+Shift+R → 仍无则重启 DSH |
| 面板空白或报 `面板取不到 host 数据` | Host 路由没挂上 / 版本不匹配 | 看 DSH 日志 `[qq-fish]`；确认版本；重启 |
| 点安装 QQ 桥没反应 | 没勾风险确认 | 去「推送与安全」勾选 |
| 提示「一键安装只支持 Windows」 | 系统不是 Windows | 用进阶路径 |
| 下载失败 | GitHub 不可达 / 镜像也不通 | 等自动换源看日志；填自己的「GitHub 下载镜像」；手动下载（见 5.3）；进阶路径 |
| 提示需要先退出 QQ | 本机桌面 QQ 在跑 | 退出 QQ 后点「启动 QQ 桥」，或点「关闭 QQ 并继续」 |
| 点「关闭 QQ 并继续」没反应 / 提示不动手 | 探测不到 QQ 安装路径或进程路径 | 手动退出 QQ，再点「启动 QQ 桥」（防止误杀别的程序的 QQ） |
| 解压失败 | 杀软拦截 / 磁盘满 | 加白名单 / 清磁盘 |
| 启动失败、UAC 被拒 | 没给管理员权限 | 重试，弹窗点「是」 |
| 一直没二维码 | NapCat 没起来 / WebUI 端口没就绪 | 看日志 lastError；重试启动；进阶路径 |
| 扫码后连不上 | token 不对 / 端口不对 | 外部模式核对 token；托管模式重装/重启 |
| 能收不能发 | 号被限制 / 消息含敏感词 | 换小号测试；降低频率；看面板错误 |
| 自动回复没反应 | 开关没开 / 群里没 @ / 节流 / 模型不可用 | 依次检查：桥在线 → 开关 → @ → 等 4 秒 → 对话页模型正常 |
| token 用量一直是 0 | 还没发生过回复/推送 | 收到一条回复后刷新看 |
| 面板数字不刷新 | 轮询被暂停 / 页面休眠 | 刷新页面 |

还搞不定：在项目仓库提 issue，附上 **DSH 版本、插件版本、面板里的错误文案、DSH 日志里
`[qq-fish]` 开头的几行**（**不要贴 token、不要把二维码截图发出来**）。
