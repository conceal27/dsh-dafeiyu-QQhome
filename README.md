# 大肥鱼插件


把 **QQ** 接进 **DeepSeek Harness**（DSH）的插件：扫码登录你自己的 QQ 号，
用你设定的人设陪聊——而且她**不只会回话**：会看图、看视频、听语音、读书、上网、自己打发时间，
也会累、会烦、会改主意。

- 扫码登录，二维码直接显示在 DSH 面板里，不用去翻日志；
- 人设聊天：名字 + 说话方式都由你定，自动回复走 DSH 已配置的模型；
- 感知：看图、看视频（ffmpeg 抽帧）、听语音（ASR）、读 PDF/EPUB/文本、收发 QQ 文件；
- 表达：语音回复（TTS 双引擎）、表情包、生图、戳一戳、QQ 空间；
- 过日子：每日日程、时间流、小屋、身体状态、需求引擎——没消息时她也在过自己的时间；
- 主动开口：主动推送 / 碎碎念 / 好奇心，**默认全关**，开启后受时段与频率限制，觉得没必要会「跳过」；
- 长期记忆：带衰减的记忆卡、笔记、纠错蒸馏、观点层（读过的书能改变看法）；
- 15 个面板页签：概览、日程、今天、聊天、身体、B 站、表情包、观点、印象、内心、人设、口吻、访问、推送与安全、高级；
- token 用量：只统计小肥鱼自己发起的调用（回复/推送/碎碎念），面板里看今日与累计；
- 数据只存在本机 `$DSH_HOME/qq-fish/`，插件没有服务器、不上传聊天记录。

> 完整能力清单见下面 [功能说明](#功能说明)——88 个后端模块、15 个面板页签、11 个技能，
> 每一项都对应代码里的真实模块，不是宣传词。

> ⚠️ **先看这一句**：本插件通过社区协议端 **NapCat** 接管**个人 QQ 号**，不是腾讯官方
> 接口，不符合腾讯用户协议；账号有被强制下线、冻结甚至封禁的风险。**强烈建议用小号**。
> 完整说明见 [SECURITY.md](SECURITY.md)。

## 功能说明

插件不是一个「收到消息 → 调一次模型 → 回一句」的转发器，而是给她配了一整套**生活与感知**：
她能看、能听、能画、能上网、能自己打发时间，也会累、会烦、会改主意。
下面按「她在干什么」分组，每一栏都对应代码里的真实模块，不是宣传词。

### 一、聊天本身

| 能力 | 说明 |
|---|---|
| 私聊 / 群聊 | 群里有三种接话方式：只回 @、只接她感兴趣的话题、每条都接（默认只回 @） |
| 合并窗口 | 私聊里你连着发几句，她会等你说完再一起回，不会一句一句插话 |
| 像人一样打字 | 按字数算打字时间、显示「对方正在输入…」、长回复拆成几条气泡、条间有停顿 |
| 语气与长度 | 短 / 正常 / 放开说 三档；单条字数上限可调 |
| 三条保险 | 发送前过一遍 `reply-guard`：拦住空话、复读、把人称叫错、把人设说崩的回复 |
| 拒绝反馈链 | 她这轮明显不想聊（不是设定，是当下情绪），会被记下来，影响接下来怎么回 |

### 二、她自己过日子

不是「等你说话了才存在」。没有消息的时候，她也在过自己的时间。

| 能力 | 说明 |
|---|---|
| 今天的日程 | 每晚排第二天的安排；每天自动生成一份 8 个时段的生活状态（凌晨 / 早上 / 上午 / 中午 / 下午 / 傍晚 / 晚上 / 深夜），确定性模板，不花 token |
| 时间流 | 每 18–42 分钟落一条「她此刻在干嘛」，纯状态、不发消息、不烧 token；聊天时她会自然提起 |
| 小屋 | 四房两厅一阳台一露台，她在哪个房间由日程推算；家具是生活痕迹，不是工具 |
| 身体 | 生理周期、精力、情绪、亲密度、性欲等维度，合成「今天你什么状态」注入提示词 |
| 需求引擎 | 渴、饿、累、闷、想被摸……攒成「不舒服」，进而驱动她主动开口或去找事做 |
| 神经-体液调节 | 主动性不是一个定时器，而是几个信号合成的一个「冲动值」 |
| 人生时间线 | 里程碑与长期记忆，形成一个连续的人生，而不是每次重启都从零开始 |

### 三、感知：她能看、能听、能读

| 能力 | 说明 |
|---|---|
| 看图 | 收到的图片直接进模型；多张图会拼成一张网格图省视觉 token |
| 看视频 | B 站 / 直链视频用 ffmpeg 抽帧拼图，配合字幕与弹幕一起理解 |
| 听语音 | ASR 双后端：硅基流动 SenseVoiceSmall（中文强、有免费额度）或本机 sherpa-onnx 模型；QQ 里的语音消息、B 站没字幕的视频都能转文字 |
| 读文件 | QQ 里的 PDF / 文本 / 代码等文件落盘并提取正文；扫描版 PDF 会渲染成页面给她「看」 |
| 读 EPUB | 她自己读书（每天挑一本，读一段，写看法），书源只用古腾堡与维基文库这类**公有领域 / 开放授权**的，不接盗版站 |
| 语义检索 | 向量化长期记忆，按语义而不是关键词翻旧事 |

### 四、说话的方式

| 能力 | 说明 |
|---|---|
| 语音回复 | TTS 双引擎：`edge-tts`（免费、无需 key）或 Breeze 云端；可设「什么场景发语音」与概率 |
| 表情包 | 收到的表情包自动收藏，聊天时自己挑一张发；也可手动管理 |
| 生图 | 火山方舟 doubao-seedream，或硅基流动；有固定形象参考图时自动带上，保证「还是她自己」 |
| 戳一戳 | 双向：她可以戳你，你戳她她会有反应 |
| QQ 空间 | 看说说的动态、点赞、评论、回复、发说说；由模型在回复里写标记触发，不是无条件乱发 |

### 五、上网与内容

| 能力 | 说明 |
|---|---|
| 联网搜索 | 免 key 的搜索，用于回答「今天出什么事了」这类她本来不知道的事 |
| 每日热点 | 60 秒读懂世界 + 微博热搜这类榜单 |
| GitHub 趋势 | 今日 / 本周最火的开源项目 |
| B 站 | 刷推荐流、看视频写观后感、点赞、收藏、发动态、回评论；@ 她也能接 |
| 梗百科 | 离线词库（从公开 API 同步），遇到不懂的梗自动查 |
| 跨群原文检索 | 同一个号在别的群说过的话，能翻出原文（而不只是摘要），带隐私边界 |

### 六、她主动开口

这几项**默认全关**，打开后受时段、频率、每小时上限约束，且模型觉得没必要时会明确「跳过」。

| 能力 | 说明 |
|---|---|
| 主动推送 | 隔一段时间看要不要找你说话，安静时段不打扰 |
| 碎碎念 | 更轻的、没由头的自言自语 |
| 开口冲动 | 四个信号合成 0~1 的冲动值，决定「现在想不想说」，而不是到点就发 |
| 好奇心 | 攒下「没搞懂的东西」，找机会自己问你 |
| 自主意图 | 「我今天想干这个」——不是被动等指令 |
| 自我唤醒 | 给未来的自己留一句话，到点再看 |

### 七、她的 11 个技能

模型读描述，自己决定要不要调、调哪个。不想让她用某个，面板里关掉即可（关掉后描述也不再注入）。

| 技能 | 用法 |
|---|---|
| 联网搜索 | `[skill:search 关键词]` |
| 看 B 站 | `[skill:bili]` |
| 翻记忆 | `[skill:memory 关键词]` |
| 查账本 | `[skill:ledger]` |
| 画图 | `[skill:draw 画面描述]` |
| 看热点 | `[skill:hot]` |
| 记笔记 | `[skill:note 标题\|正文]` |
| 翻笔记 | `[skill:notes]` |
| 记着的事 | `[skill:memo status/task/list …]` |
| 看 GitHub 趋势 | `[skill:github]` 或 `[skill:github weekly]` |
| 挑表情包 | 发送时自动附带 |

技能查回来的内容不会原样贴给你（那样会露出「[查到：…]」这种括号），而是**再要一遍模型，用她自己的口吻讲出来**。

### 八、工具层（只认主人）

`lib/agent-tools.mjs`：**只响应主人私聊**，命令走白名单、禁止 shell 元字符、路径锁在家目录、有超时与输出截断、全量审计。包括只读、家目录读写、受限命令、网页抓取四类。

### 九、面板的 15 个页签

按「她 → 聊天 → 身体 → 记忆 → 设置」分组：

| 分组 | 页签 |
|---|---|
| 她 | 概览、日程、今天 |
| 聊天 | 聊天 |
| 身体 | 身体、B 站、表情包 |
| 记忆 | 观点、印象、内心 |
| 设置 | 人设、口吻、访问、推送与安全、高级 |

面板配色跟随 DSH 浅色 / 深色主题。**概览**里有二维码、NapCat 安装进度、紧急停止。

### 十、记忆怎么存

| 层 | 内容 |
|---|---|
| 长期记忆卡 | 按条存，会**衰减**（久不用的权重下降），不是只涨不删的流水账 |
| 记忆账本 | 记录记忆是否被丢过 / 改过，可自查 |
| 笔记 / 备忘录 | 她自己的笔记本 + 「一直记着的事」与到点提醒 |
| 纠错蒸馏 | 你纠正她之后，把教训提炼成规则，下次不再犯同一个错 |
| 人格演化 | 人设不是死的，长期交互会让她慢慢偏移（可关） |
| 观点层 | 读过的书、看过的视频能**改变她的看法**，而不只是多记几条事实 |

所有数据都在本机 `$DSH_HOME/qq-fish/`，插件没有服务器。

## 三步开始

```
① 装插件            ② 连上 QQ                    ③ 开聊
DSH 插件页           面板「概览」→ 连接 QQ          面板「人设」定名字/说话方式
「添加插件」          → 自动装/启动 NapCat          「推送与安全」勾选小号风险确认
→ 立即启用            → 手机 QQ 扫码登录            → 打开自动回复 / 主动推送
```

第一次用大概 5～10 分钟（其中 NapCat 下载 34～118 MB 取决于你的 QQ 装没装）。
后面的步骤里，按钮文案可能随版本微调，**以你面板里看到的为准**，流程不变。

## 环境要求

| 项目 | 要求 |
|---|---|
| DeepSeek Harness | 桌面版 **0.2.1-rc.3 或更新**（本版本在该版上验证；更旧的版本可能没有插件页/左栏面板 slot） |
| 操作系统 | **Windows 10 / 11**：支持「一键安装 QQ 桥」全托管路径；macOS / Linux 用进阶路径（自己跑 NapCat） |

| QQ | 建议专门的**小号**；同一个号不能和桌面版 QQ 同时登录 |
| 网络 | 能访问 npm registry（装插件）与 GitHub Releases（下 NapCat）；直连失败会自动换镜像 |
| 磁盘 | 托管 NapCat 约占 150～300 MB（含 QQ 的包则更大） |

## 安装

插件包名：**`dsh-dafeiyu-home`**。任选一种方式。

> 主要装法：**GitHub 仓库地址 / Release tarball**。npm 上的同名包不一定与这里的代码同源，装之前先核对版本与提交。
> ⚠️ DSH 有 pnpm 供应链观察期（`minimumReleaseAge`）：新版本发布后短时间内只填包名可能装到旧版，建议在「添加插件」里**指定版本**（先卸载旧版）。
> 国内网络慢时可在安装源里选「中国大陆镜像源」（只加速 npm 包，不加速 NapCat 下载）。

### 方式一：插件页「添加插件」（推荐，适合所有人）

1. 打开 DSH，左侧栏点「插件」（有的版本在 设置 → 插件）；
2. 点右上角 **添加插件**；
3. 在输入框里填下面任意一种，点安装：
   - **Git 地址（推荐）**：`https://github.com/conceal27/dsh-dafeiyu-QQhome`
   - **Release tarball**：
     `https://github.com/conceal27/dsh-dafeiyu-QQhome/releases/download/v2.0.2/dsh-dafeiyu-home-2.0.2.tgz`
   - 本地 `.tgz` 路径，或本地目录：例如 `~/dsh-dafeiyu-home`（开发/离线用，换成你本机实际目录）
   - npm 包名：`dsh-dafeiyu-home` ⚠️ npm 上的同名包与本仓库**不同源**，只有确认过版本和提交才用这条
4. 安装完成页会显示实际版本，点 **立即启用**；
5. 浏览器按 **Ctrl + Shift + R** 强刷一次页面。

> **看到什么算成功**：左侧栏出现「大肥鱼插件」图标，点开是插件面板；
> 插件列表里它的开关是开的。
>
> **失败怎么办**：
> - 提示 `not-a-bundle`：说明填的不是本插件（普通依赖包不算插件）；
> - 提示需要重启（`restart-required`）：关掉 DSH 重新打开；
> - 页面没变化：先强刷；还不行看「设置 → 内置插件」列表里有没有它，再决定重装。

### 方式二：命令行（适合开发/脚本）

```bash
# 先确认 profile 名字：桌面版通常是 desktop，浏览器版是 web
# 从 GitHub 装（推荐）
dsh plugin --profile <profile> add https://github.com/conceal27/dsh-dafeiyu-QQhome

# 从 Release tarball 装
dsh plugin --profile <profile> add \
  https://github.com/conceal27/dsh-dafeiyu-QQhome/releases/download/v2.0.2/dsh-dafeiyu-home-2.0.2.tgz

# 本地目录（开发时）
dsh plugin --profile <profile> add ~/dsh-dafeiyu-home

# 卸载
dsh plugin --profile <profile> remove dsh-dafeiyu-home
```

> 桌面版注意：桌面版包管理由 Desktop 壳负责，普通用户请优先用方式一；命令行更适合 web profile 或开发机，装完同样要重启 DSH / 强刷页面。

### 方式三：tarball / 离线包

```bash
# 在仓库目录里打包
npm pack                      # 产物：dsh-dafeiyu-home-<版本>.tgz
# 然后在插件页「添加插件」里填这个 .tgz 的绝对路径，或：
dsh plugin --profile <profile> add ./dsh-dafeiyu-home-2.0.2.tgz
```

适合内网机器：把 `.tgz` 拷过去安装；托管安装 NapCat 仍要能访问 GitHub 或用镜像。

### 装完怎么确认

左侧栏有「大肥鱼插件」入口、面板能打开并能看到版本号；DSH 日志里有 `[qq-fish] 已挂载 v2.0.2` 与 `桥接已初始化`。

### 升级到新版本

先卸载再装，别原地覆盖（DSH 的 pnpm 有供应链观察期，直接 `add` 同一个包名可能还是旧版）：

```bash
# 1. 先卸载旧版（状态目录不动，聊天记录/记忆都还在）
dsh plugin --profile web remove dsh-dafeiyu-home
# 2. 再装新版
dsh plugin --profile web add https://github.com/conceal27/dsh-dafeiyu-QQhome
# 3. 重启让后端生效（改的是 lib/*.mjs，ESM 已加载进内存，不重启不生效）
sudo systemctl restart dsh-web      # Linux
# Windows 桌面版：面板里点重启，或退出 DSH 再打开
```

浏览器面板改了要 **Ctrl + Shift + R** 强刷。

状态目录 `$DSH_HOME/qq-fish/` 在升级过程中不会被删，所以记忆、聊天记录、表情包都保留。
如果你就是想彻底重来，才去删它（见下面「卸载」）。

### 卸载

1. 面板 →「推送与安全」→ **紧急停止**；
2. 插件页卸载（或方式二的 `remove`）；
3. 手动删除状态目录 `%USERPROFILE%\.dsh\qq-fish`（清掉聊天记录、token、托管 NapCat）。

详见 [SECURITY.md](SECURITY.md) 第 9 节。插件不会动腾讯 QQ 自己的数据。

## 首次使用（面板向导）

打开左侧栏「大肥鱼插件」→ 概览页会有一个四步向导，做完就通了。

### 第 1 步：确认风险（一次性）

- **点哪里**：「推送与安全」→ 勾选「我用的是小号，已知可能被风控 / 封禁，并自行承担风险」→
  点「我已了解，确认」；
- **为什么**：这是知情同意。没勾选时，安装 QQ 桥、登录、主动推送都会被拒绝，并提示
  先去勾选；
- **看到什么**：勾选后提示保存成功，之后不再问。

### 第 2 步：装好 / 启动 QQ 桥（Windows 托管）

- **点哪里**：「概览」→ **连接 QQ**（或「一键安装 QQ 桥」）；
- **会发生什么**（进度条 + 可展开日志）：
  1. 探测本机 QQ 与 NapCat；
  2. 没装 NapCat 就下载（本机已有 QQ → 34 MB 的 Shell 包；没装 QQ → 带 QQ 的
     118 MB 包）；下载中断会**自动换源**重试，日志显示「改用下载镜像：xxx」；
  3. 解压到 `$DSH_HOME/qq-fish/napcat/<版本号>/`，写只监听 `127.0.0.1` 的 WebUI 与
     OneBot 配置；
  4. 启动 NapCat（可能弹 **UAC**，点「是」）；
  5. 等二维码出现（最多约 90 秒）。
- **装完提示 QQ 在运行**（同一个号不能和桌面 QQ 同时在线）：按提示**退出电脑上的 QQ**，
  再点「启动 QQ 桥」；或点面板上的「关闭 QQ 并继续」——它只结束插件探测到的**那一份**
  QQ.exe，不会乱杀；探测不到路径时会拒绝动手，让你手动退出。
- **失败怎么办**：
  - UAC 弹窗是正常的，点「是」即可；拒绝会启动失败；
  - 杀软/Defender 拦注入：把 NapCat 目录加白名单后重试；
  - 端口被占：插件会自动挑空闲端口，稍等它换一个；
  - 还是失败：看面板日志的 stage 与 `lastError`，或直接走「进阶：我自己有 NapCat」。

### 第 3 步：手机扫码登录

- **点哪里**：二维码出现后，用**手机 QQ**（要登录的是那个号）→ 右上角 **+** →
  **扫一扫**；
- **看到什么**：面板会依次显示「等待扫码 → 已扫码，请在手机上确认 → 初始化中 →
  已登录」，账号显示为脱敏值（如 `12****78`）；
- **失败怎么办**：
  - 二维码过期：点 **刷新二维码**，重新扫；
  - 手机上点了取消：回到「等待扫码」，再扫一次；
  - 提示同账号冲突：先退出电脑上的桌面版 QQ（同一个号不能两处同时登录）；
  - 之前登录过时会列出「一键登录」候选，点上次的账号可复用，不一定每次都要扫码。

### 第 4 步：认一下人设

- **点哪里**：「人设」→ 改「小肥鱼的名字」和「说话方式」→ **保存人设**；
- **看到什么**：名字会用于提示词和界面标题；保存成功提示「已保存」；
- **注意**：默认人设是作者写的出厂设定，随时可改；改坏了点「恢复出厂人设」。

### 第 5 步：打开开关（按需，默认全关）

- **自动回复**：有人和她说私聊/在群里 @ 她时回一句；
- **群聊接话方式**（默认「只回 @我」）：
  - **只回 @我**：最省心，不刷屏（推荐长期开）；
  - **只接感兴趣的话题**：填兴趣关键词 + 让模型判断「这条值不值得插话」，再叠最短间隔/每小时上限/概率，避免见谁都接；
  - **每条都接**：不推荐，人多必刷屏、也更容易被风控；
- **主动推送 / 碎碎念**：默认关，开启后在「推送与安全」里选目标、时段和间隔；
- **隐私模式**：默认开，面板展示聊天正文时会打码手机号、身份证号（⚠️ 本机聊天文件仍是原文，见 [SECURITY.md](SECURITY.md)）。

到这一步已经可以用了。想验证：用另一个号给她发一句私聊，看面板「聊天」里有没有记录、
有没有回复。

## 进阶：我自己有 NapCat

适合：本机已装好自己的 NapCat、用 macOS/Linux、或托管安装失败想手动接管。

> **NapCat 有哪些坑/风险、怎么判断自己的 NapCat 配好了、常见报错怎么排**：
> 见 [docs/napcat-faq.md](docs/napcat-faq.md)（也是给其它用户看的常见疑问合集）。

### 在 NapCat 里开好 OneBot 11

1. 打开你的 NapCat WebUI（默认 `http://127.0.0.1:6099`，按你安装时的配置）；
2. 进 **网络配置**，添加一个 **WebSocket 服务器**（正向 WS）：
   - host：`127.0.0.1`（**不要** `0.0.0.0`）
   - port：例如 `3001`
   - token：设一个随机串并记下来（可空，但**强烈建议设**）
   - 消息格式：`array`；心跳：`30000`
3. 保存并启用，确认 NapCat 已登录（手机 QQ 扫码）。

### 在插件面板里填

- **点哪里**：「概览」→ 展开「高级：我自己有 NapCat」；
- **填什么**：
  - `wsUrl`：`ws://127.0.0.1:3001`（必填，连消息用）
  - `wsToken`：上面那个 token（有就填，不回显）
  - `webuiUrl` / `webuiToken`（可选）：填了插件才能帮你在面板里拉二维码、看登录态、
    列「一键登录」候选；不填就自己去 NapCat 里登录，登录好后插件只负责连 WS；
- **保存后**：插件会切到外部模式，**不会**启动/停止你自己的 NapCat，也**不会**接管它的
  进程——这是有意的，避免误杀你正在用的实例。
- **下载镜像（可选）**：面板「QQ 桥」卡片里有「GitHub 下载镜像（可空）」，对应配置
  `config.napcatMirror`；留空就用内置公共镜像自动换源。

### 安全要求（外部模式同样适用）

- WebUI 与 OneBot 只绑 `127.0.0.1`，不要端口映射、不要内网穿透；token 别贴进聊天/截图；
- 不需要时在 NapCat 里关掉服务。

## 面板里有什么

面板分四块（新手按「概览 → 二维码 → 人设 → 开关」的顺序走就不会乱）；整体配色自动跟随 DSH 的浅色/深色主题（设置里换外观即时生效，不用刷新）：

| 区块 | 能做什么 |
|---|---|
| **概览** | 连接状态与账号；四步向导；二维码与「获取 / 刷新二维码」；NapCat 安装进度与日志；QQ 在跑时的「关闭 QQ 并继续」；「一键登录」候选；今日收发/token 概览；**紧急停止** |
| **聊天** | 左列会话（按最后消息倒序、显示最后一条与时间），右侧消息流（入/出分列、带时间戳、日期分隔），底部可发消息；「同步联系人」拉好友/群；QQ 号全部脱敏 |
| **人设** | 名字与说话方式编辑/保存、恢复出厂人设；自动回复、群聊接话方式（只回@ / 只接感兴趣的话题 / 每条都接）与频率设置；单条字数上限 |
| **推送与安全** | 主动推送/碎碎念开关与「现在发一条」；发送目标、间隔、安静时段、每小时上限；隐私模式；小号风险确认；token 用量（今日/累计/调用次数/近 14 天）；数据只存本机说明 |

「紧急停止」= 断开 QQ 桥 + 停掉插件托管的 NapCat + 停掉主动推送定时器；**数据保留**。
它不会删聊天记录，也不会动你自己的 NapCat（外部模式）。

## 常见问题

**Q1：安装/启动时弹 UAC，是病毒吗？**
不是。NapCat 的启动器要向 QQ 进程注入 hook，需要管理员权限。弹窗里点「是」；
不放心可以先看这个文件夹是不是你自己装的 `qq-fish\napcat\` 下的 `launcher.bat`。
如果实在不想给权限，用「我自己有 NapCat」进阶路径。

**Q2：提示「同账号不能同时登录」/ 桌面 QQ 被顶下线**
一个 QQ 号同一时间只能有一个登录态。NapCat 接管后，电脑上的桌面版 QQ 会被顶下线。
建议：用**小号**跑插件，桌面 QQ 挂主号；或者用插件时不登桌面 QQ。

**Q3：端口被占用 / 端口变了？**
托管模式会自动探测空闲端口；如果你手动配过固定端口又被别的程序占了，改成自动/换一个。
外部模式请以 NapCat 里实际显示的端口为准。

**Q4：二维码过期、刷不出来？**
点「刷新二维码」再扫；还是不行就等 NapCat 后台重启十几秒（面板会提示），再点一次。
手机 QQ 的「扫一扫」要在已登录该号的手机上打开。

**Q5：掉线了怎么办？**
插件会自动重连（指数退避）；NapCat 掉登录态时面板会提示重新扫码。**不要**短时间内反复重启登录——频繁重登是风控触发点，等几分钟、换个网络再试。

**Q6：token 填错了会怎样？**
外部模式下表现为连不上 OneBot（面板提示未连接/地址或 token 不对）。回 NapCat 核对 token 重填；托管模式是插件自动生成的，一般不用手填。

**Q7：杀毒软件/Defender 报警拦截？**
NapCat 的 DLL 注入容易被启发式拦截。把托管目录（`qq-fish\napcat\`）加入白名单后重试；
仍拦截就改用外部模式。

**Q8：GitHub 下载很慢 / 中断？**
插件会**自动换源**重试：填了镜像就先试你的镜像，然后 GitHub 直连，再试内置的
`gh-proxy.com`、`ghproxy.net`；面板日志会显示「改用下载镜像：xxx」。都失败再手动
下载 `NapCat.Shell.zip`（或自带 QQ 的 `NapCat.Shell.Windows.Node.zip`）解压到
`qq-fish\napcat\<版本号>\` 后点「重新探测」，或走「我自己有 NapCat」。
⚠️ 第三方镜像不保证文件完整性；插件会校验 zip 文件头，并在系统自带 tar 可用时预检压缩包
条目路径（拒绝路径穿越），但请尽量用直连或你信任的镜像。

**Q9：为什么不用官方 QQ 机器人（q.qq.com）？**
官方机器人需要主体认证与 AppID/AppSecret，**不能扫码接管个人号**，拿不到完整的私聊/
群聊记录，主动消息额度也受限。本插件要的就是"用我自己的 QQ 号陪聊 + 看本地记录 + 主动
推一句"，所以走本机 NapCat（OneBot 11）。官方机器人能力见腾讯文档，本插件不提供该路径。

**Q10：自动回复没反应？**
按顺序查：① 概览里桥是否「在线」；② 「人设」里自动回复开关；③ 群聊是否没 @ 她（群里默认只回 @）；④ 是否触发节流（同会话 4 秒一条）；⑤ 模型是否可用（DSH 对话页能否正常回复）。

**Q11：群聊里她回得太快、每句都接，怎么办？**
用「人设 → 群聊接话方式」控制：
- **只回 @我**（默认）：只有被 @ / 点名才回，最省心；
- **只接感兴趣的话题**（推荐）：填兴趣关键词（如 游戏、显卡、电影、网购、值不值），命中的才接；
  没命中的会让模型按人设判断「要不要插一句」；再叠加下面的频率限制，不会见谁都接；
- **每条都接**：不推荐，人多必刷屏、也更容易被风控。
频率限制（同一群生效）：最短间隔（默认 120 秒）、每小时上限（默认 6 句）、接话概率（默认 100%，调低更安静）。
智能判断每条候选会多一次很小的模型调用（只输出 `[插话]/[跳过]`），会多一点点 token。

**Q11b：群聊为什么不回？**（和上一题相反）
1. 默认只回「被 @ 的消息」——想接话题就切到「只接感兴趣的话题」；
2. 关键词没命中且模型判断「跳过」时不会接（可以在关键词里加你常聊的话题）；
3. 触发了频率限制：同一群最短间隔/每小时上限、或接话概率设得太低；
4. 群里消息没 @ 她时，她只会在「smart/all」模式下考虑，且默认每群每小时最多 6 句。

**Q12：token 用量为什么和对话页统计不一样？**
这里只统计**小肥鱼自己发起的调用**（自动回复/主动推送/碎碎念），不含你在对话页里的消耗；
数据来自本地 `usage.json`，口径以面板说明为准。

**Q13：紧急停止会删数据吗？**
不会。它只断开桥、停掉托管的 NapCat、停掉定时器；配置、聊天记录都保留。

**Q14：卸载会删我的 QQ 数据吗？**
不会。插件不碰腾讯 QQ 的用户数据；但要记得手动删 `%USERPROFILE%\.dsh\qq-fish`，否则
聊天记录和 token 会留在磁盘上。

**Q15：NapCat 有什么问题/风险？我自己有 NapCat 怎么接？**
NapCat 是社区协议端（非官方、有封号风险，建议小号），还可能遇到：同账号不能与桌面 QQ
同时登录、UAC/杀软拦截注入、QQ 自动更新导致失效、WebUI/OneBot 默认可能暴露、掉线需重连。
完整的风险清单、自建 NapCat 的 OneBot 11 配置示例、面板外部模式填写步骤和报错对照表见
[docs/napcat-faq.md](docs/napcat-faq.md)。

## 安全与合规声明

- 本插件通过社区协议端 **NapCat** 接管**个人 QQ 账号**，属于**非官方接口**，不符合腾讯
  用户协议；账号存在被强制下线、临时冻结、永久封禁的风险，**请使用小号并自行承担风险**。
- 插件**不提供**群发、营销、爬取他人信息、自动加好友等能力；请勿用于此类用途。
- 聊天记录、token、人设等数据**只保存在本机**，插件不上传；但请不要在聊天里发送密码、验证码、身份证等敏感信息。
- 本插件**不承诺**官方支持、不承诺不被风控；详细数据落点、脱敏、威胁模型见 [SECURITY.md](SECURITY.md)。

## 已知限制

- **托管安装只做 Windows**：macOS/Linux 请自己跑 NapCat 后用进阶路径；
- NapCat 与不同 QQ 版本的兼容性由 NapCat 社区维护，遇到注入/启动失败先升级 NapCat；
- 微信/QQ 官方风控规则随时变化，插件只能通过低频、限额、默认关闭来降低风险；
- 只支持文本消息收发（图片/语音/文件在记录里显示为占位符）；token 统计是本地口径，可能和模型服务商账单有差异。

### 0.1.3（2026-10-26）

- **修复外部模式误导致安装“回到安装界面”**：如果配置是「使用你自己的 NapCat」但没有填 OneBot 地址，原来点「一键安装」装完也不会被托管模式识别，看起来像回到安装界面。现在：
  - 一键安装会自动把这种空外部模式切回插件托管；
  - 面板会显示警告并提供「切回插件托管」按钮；
  - 外部模式必须填 WebSocket 地址，保存空地址会被拒绝；
  - 高级里新增「切回插件托管（清空外部地址）」。
- 测试：NapCat 套件 28 例（新增空外部地址拒绝/切回托管回归）；client smoke 71 例。

### 0.1.2（2026-10-26）

- **新增「取消安装」按钮**：NapCat 安装/下载过程中可以随时取消；Host 会中止下载任务，安装进度落「已取消」，不会误报安装失败，也不影响已装好的 NapCat。
- 取消后可以重新点「一键安装 QQ 桥」；已经下载了一半的临时文件会由下次安装重新处理。
- **下载自动换源加速**：NapCat 下载默认先走 `gh-proxy.com` → `ghproxy.net` → `ghfast.top` 公共加速，最后才回退 GitHub 直连；如果某个源 20 秒没有进度，会自动中止并换下一个源，不再卡在慢直连上。
- 注意：DSH「添加插件」里的「中国大陆镜像源」只加速 **npm 包**，不加速 NapCat 的 GitHub 下载；NapCat 下载源由插件自己的逻辑/「高级 → GitHub 下载镜像」控制。
- 面板安装中增加「手动下载 NapCat 包」链接；下载太慢可取消后重试或手动下载。

### 0.1.1（2026-10-26）

- **修复崩溃**：GitHub API 返回 403（未登录限流）时，NapCat 安装任务的异常没有被兜住，会变成 unhandledRejection，导致 DeepSeek Harness 宿主「应用无法启动或已意外停止」。现在安装失败只会把面板的「安装任务」标记为失败并显示原因，不再拖垮宿主。
- **增加兜底**：API 403/429 时自动改为访问 `releases/latest` 页面、跟随跳转解析 tag，再拼官方下载地址（不消耗 API 配额），很多时候可以直接继续安装。
- 测试：NapCat 套件 26 例（新增 403 降级/失败不崩溃回归）。
