# 大肥鱼插件 · dsh-dafeiyu-home

> 把 QQ 接进 DeepSeek Harness，给她一个会记得你、会主动找你、会说话也会看图的「她」。

一个跑在 DSH 里的 QQ 人设机器人插件。你定人设，她记日常；你发消息，她回你；
她会在你没吭声的时候自己找上门，也会在半夜困得迷迷糊糊时用一条语音敷衍你。

---

## 她能做什么

**聊得像个活人**
- 人设由你写：名字、说话方式、脾气、小习惯，都是你说了算
- 群聊和私聊分开处理：群里被 @ 才接话，私聊随叫随到
- 会接梗、会追问、会记住上次没聊完的那句话

**会记忆**
- 记得你说过的事、她做过的事、你们之间的约定
- 记忆会随时间变淡，重要的不会丢；想不起来时她会说「记不清了」，不瞎编
- 面板里能翻她的记忆卡，哪天想不起你们聊过什么，去那儿找

**会说话**
- 文字回复之外，还能发语音（专属音色，撒娇和正经事用不同声线）
- 能听懂你发的语音：转成文字，再回你
- 偶尔发张表情包，不是纯文字机器

**会看图**
- 你发的图会先被读成文字，她再据此回你——看不懂的图她会直接说看不懂

**会自己找事做**
- 主动推送：隔一阵子发条消息，内容由她按当下心情挑，不是定时复读
- 碎碎念、日记、心情、作息，都有各自的小系统

**面板好用**
- 网页面板里看聊天记录、她的状态、记忆、token 用量
- 常用操作点点就行，不用敲命令

## 三步开始

```
① 装插件              ② 连上 QQ                ③ 开聊
DSH 插件页             面板「概览」→ 连接 QQ      面板「人设」写名字和说话方式
「添加插件」            → 扫码登录                → 「推送与安全」勾选风险确认
→ 立即启用              → 桥自动就绪              → 打开自动回复
```

第一次大概 5～10 分钟。

## 环境要求

| 项目 | 要求 |
|---|---|
| DeepSeek Harness | 桌面版 0.2.1 或更新 |
| 操作系统 | Windows 10/11 一键装桥；macOS / Linux 自己跑 NapCat |
| Node | 插件跟着 DSH 跑，不用单独装 |
| QQ | **强烈建议用小号**，同一个号不能和桌面版 QQ 同时登录 |
| 网络 | 能访问 npm registry；NapCat 从 GitHub Releases 下载，直连失败会自动换镜像 |
| 磁盘 | 托管 NapCat 约 150～300 MB |

## 安装

包名 `dsh-dafeiyu-home`，已发布到 npm。

1. DSH 左侧栏「插件」→ 右上角「添加插件」
2. 填 `dsh-dafeiyu-home`（或本地路径 / tarball）
3. 装完点「立即启用」
4. 浏览器 `Ctrl + Shift + R` 强刷一次

> 新版本发布后有 pnpm 的观察期，装不到最新就指定版本号。

## 配置

| 项 | 在哪 | 说明 |
|---|---|---|
| 人设 | 面板「人设」 | 名字、说话方式、习惯，随便写 |
| 模型 | DSH 设置 → 模型 | 她跟 DSH 当前模型走 |
| 语音合成 | 面板「语音」 | 专属音色，云端按字计费 |
| 语音识别 | 面板「语音」 | 官方接口或本地，二选一 |
| 图片识别 | 自动 | 官方 OCR，按页计费 |
| 主动推送 | 面板「推送与安全」 | 默认关，打开后受时段和频率限制 |

---

## 关于风险，先把话说清楚

本插件通过社区协议端 **NapCat** 接管**个人 QQ 号**，**不是腾讯官方接口**，
不符合腾讯用户协议。账号有被强制下线、冻结甚至封禁的风险。

**强烈建议用小号。** 用主号出问题，别怪插件。

---

## 数据

所有数据只存在本机 `$DSH_HOME/qq-fish/`：聊天记录、记忆、日记、配置。
插件没有自己的服务器，不上传任何聊天内容。

## 更新日志

### 2.1.0（2026-11-18）

在 2.0.7 基础上的修复与增强：

**修复**

- 修 `usage` 未定义导致的无限重发（2.0.7 原生问题，会让同一句话连发九遍）
- 修主动推送 / 碎碎念被记成 `engine` 来源，导致同一条消息在记录里出现两份
- 修**空间评论读错字段**：QQ 返回的评论列表字段是 `conlist` 而不是 `commentlist`，
  读错之后她永远看不到评论内容，自然分不清谁评论的、也不会回复主人
- 修**空间评论只在主人私聊时才拉取**：主人在空间评论了，只要没私聊她，她就永远不知道。
  现在改为后台定期刷新（默认 10 分钟一次），与私聊解耦
- 修自唤醒路径漏清理 `[skill:...]` 内部指令，导致把 `[skill:search ...]` 当聊天内容发出去
- 修 `[图片]` 占位在正文和图片记录里各记一份
- 修**连续性提示词逼她反复延续同一话题**（同一件小事说三四遍），改为「只防矛盾，不逼延续」
- 修 **`scanOwnerPlan is not defined`**：`engine.mjs` 调用了 `followup.mjs` 的函数却从未 import，
  「追问」功能从上线起就没生效过
- 修**作息自动演化会把 `wakeHour` 推到 12 点**，导致 0–12 点所有后台功能（B 站、空间、分享）
  被睡眠闸门挡掉。现在上限收到 10，且单次最多挪 1 小时
- 修 **B 站评论不 @ 主人**：`biliCommentAt` / `ownerBiliName` 两个配置只在 store 里定义过，
  发评论的代码从来没读过它们

**新增**

- **关心系统**（`lib/care.mjs`）：11 类需求状态（渴/饿/累/病/冷/热/失眠/压力/孤独/忙/考试），
  带 TTL，注入到主人私聊的提示词里；她用 `[cared:key]` 标记「这次已经关心过了」
- 空间评论后台刷新（见上）
- 发布前脱敏自查脚本 `scripts/scan-secrets.mjs`

**工程**

- 所有状态目录统一跟随 `DSH_HOME`，不再写死绝对路径
- 找回 2.0.7 升级时丢失的 `lib/breeze-voices.mjs`、`lib/github-trending.mjs`、
  `scripts/`、`tests/`
